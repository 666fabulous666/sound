- The color hue picker exposed to the user is not consistent with the colors of the trakcs. Use unified hsl <-> rgb logics for both properties panel and timeline panel.
- The label that is written to the left of the tracks in the timeline panel should be the current ones if the TrackNode doesn't have a name, or the name otherwise.
- `Sequence::draw` (`synth-core/src/engine/score/sequence.rs`) builds multiple temporary vectors (`ts`, `ds`, shuffled tuple vec, cloned notes) and iterates over the artificial `0..32768` range regardless of loop length. We should rewrite it to derive the iteration bound from `loop_len/time_quantum`, reuse buffers, and avoid unnecessary `collect_vec` calls so large scores don’t stutter when regenerating.
